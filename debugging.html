Debugging & Pseudo Code

Flowchart 1 — Miles Per Gallon

Debugged Pseudocode

start
  input milesTraveled
  input gallonsOfGasUsed
  milesPerGallon = milesTraveled / gallonsOfGasUsed
  output milesPerGallon
stop

Flowchart 2 — Cost Per Day

Debugged Pseudocode

start
  input rent
  costPerDay = rent / 30
  output costPerDay
stop

Flowchart 3 — Tablespoons to Teaspoons

Debugged Pseudocode

start
  input tablespoons

  output teaspoons

Flowchart 4 — Monthly Budget

Debugged Pseudocode

start
  input monthlyPay
  input rent
  input utilities
  input groceries

  totalBills = rent + utilities + groceries
  discretionary = monthlyPay - totalBills

  output monthlyPay
  output totalBills
  output discretionary
stop
